# OmniHub

Landing page and umbrella for small work-related web apps.

Each tool lives in its own directory and is reachable at `/{slug}`.

| Tool | Path |
| --- | --- |
| SDD made simple | [`/sddms`](./sddms/) |

Convention: add `toolslug/index.html` (and any assets for that tool). The hub card on the root page links to that path.

SDD Made Simple is an internal training and reference tool for presenting the Status Disclosure Document using the REAL CAR mnemonic. It is not a customer-facing SDD substitute.
